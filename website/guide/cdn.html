CDN

Load the Snice runtime once, then add CDN component builds. No bundler needed — just <script> tags.

<!-- Load runtime once --> <script src="snice-runtime.min.js"></script> <!-- Add components --> <script src="snice-button.min.js"></script> <script src="snice-input.min.js"></script> <script src="snice-modal.min.js"></script>

The runtime is ~34KB gzipped. Each component adds ~1–114KB. No duplication regardless of how many components you use.

Best for: CMS pages, WordPress, static sites, landing pages, dashboards.
