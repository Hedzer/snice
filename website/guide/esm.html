ESM + Bundler

Install the package and use with Vite, esbuild, or Rollup. Full framework with decorators, routing, and controllers.

# Install npm install snice # Or scaffold a full project npx snice create-app my-app import { element, property, render, html } from 'snice'; @element('my-counter') class MyCounter extends HTMLElement { @property({ type: Number }) count = 0; @render() template() { return html` <button @click=${() => this.count++}> ${this.count} </button> `; } }
