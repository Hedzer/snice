Styles

Styles are applied once to the managed render root. Shadow-root styles are encapsulated; light-root styles follow normal CSS scoping.

@styles() css() { return css` :host { display: flex; align-items: center; padding: 0.5rem; } :host([done]) span { text-decoration: line-through; opacity: 0.5; } `; }

Use :host to style the element itself. :host([done]) targets when the done attribute is present.
