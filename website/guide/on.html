Event delegation

Handle events declaratively with the @on decorator instead of inline handlers.

@on('click', '.delete') handleDelete(e) { const id = e.target.dataset.id; this.items = this.items.filter(i => i.id !== id); } @on('input', 'input.search', { debounce: 300 }) handleSearch(e) { this.filter = e.target.value; }

Delegation works on shadow DOM elements. Built-in debounce and throttle options.
