Keyboard shortcuts

Filter events by key or key combo directly in the template.

@render() template() { return html` <input placeholder="New task..." @keydown:Enter|prevent=${this.addTask} @keydown:Escape|stop=${this.clear} /> `; }

Combos: @keydown:ctrl+s, @keydown:shift+Enter. Compose |prevent, |stop, |immediate, |once, |capture, |passive, and |self.
