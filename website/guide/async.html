Async content

Promises and async iterables render directly in node expressions. Replacing a source ignores stale results; disconnecting stops active iterator consumption.

userView = fetch(this.url) .then(response => response.json()) .then(user => html`<user-card .user=${user}></user-card>`) .catch(error => html`<p role="alert">${error.message}</p>`); return html`${this.userView}`;

Promise cancellation remains explicit: own an AbortController in the component lifecycle when a fetch must be aborted.
