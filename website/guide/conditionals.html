Conditionals

Virtual control-flow tags add no wrappers and preserve each branch's DOM identity while it is inactive.

@render() template() { return html` <if ${this.loading}> <snice-spinner></snice-spinner> <else-if ${this.error}> <p role="alert">${this.error.message}</p> </else-if> <else> <task-list .items=${this.items}></task-list> </else> </if> <case ${this.status}> <when value="idle">Idle</when> <when ${OFFLINE_STATE}>Offline</when> <default>Working</default> </case> `; }

Static <when value="..."> matches strings. A dynamic <when ${value}> uses Object.is for typed values and object identity.
