Column Fit: Squish vs Scroll

The same eight columns in the same narrow box. column-fit="squish" makes the frame the constraint — the columns share it, content ellipsises, and nothing scrolls sideways. The default scroll keeps each column at its minimum width and scrolls instead. Both stay resizable: drag a header edge in the squish table and its neighbours give up the width.
